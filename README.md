# Margin

用二维码的纠错余量，把文字、Logo 或照片融入黑白二维码。支持 Windows 桌面界面和命令行，导出 PNG / SVG。

## 工作原理

保留定位、时序、对齐、格式、版本等功能图案，只改写数据区域。按 Reed–Solomon 纠错块统计实际受影响的码字，以图案轮廓和细节的恢复收益分配预算。

- 每块纠错容量由二维码版本和纠错等级计算，不使用固定的 14 码字上限。
- **扫码优先**：有效预算不超过用户设置及每块纠错容量的 70%，优先使用较小版本。
- **还原优先**：有效预算不超过用户设置，每块至少留一个码字余量，优先选择图案一致度较高的扫码成功结果。
- 自动选择掩码时比较全部 8 个掩码；自检失败会降低预算重试。
- PNG、SVG 和界面预览共用最终矩阵，包括重试后实际采用的版本、掩码和预算。

生成后的 ZXing 自检验证编码内容是否正确；真实拍摄和印刷的识别效果还取决于模块尺寸、光线等条件。

## 图形界面

安装依赖后运行 `python app.py`，或打开打包后的 `Margin.exe`。

1. 填写扫码内容。裸域名自动补上 `https://`；例如 `www.hurkin.top` 会变成 `https://www.hurkin.top`。
2. 选择中心图案来源：**文字**或**图片**。文字留空可生成普通二维码。
3. 文字模式支持搜索全部 Windows 系统及当前用户已安装字体、选择粗体/斜体等字形，也可导入 TTF、OTF、TTC、OTC。字体集合中的字体分别列出；缺字或字体加载失败会明确提示。
4. 图片模式支持 PNG、JPEG、WebP、BMP、TIFF，自动校正照片方向、处理透明通道，并裁掉外围白色/近白色空白。图片内部的白色孔洞保留，不做主体抠图。多帧图片只读取首帧。
5. 选择生成策略和版本。预算、图案占比、点径以及图片高级设置中的阈值、对比度均提供**滑块 + 输入框**，双向同步。黑白阈值默认自动，可开启手动调整。
6. 自动生成在后台执行，也可点击「生成」或按 Ctrl+Enter。参数变化后立即停用保存，过期后台结果不会覆盖最新设置。扫码自检失败时不可保存。

设置区可滚动，窗口可调整大小。图片模式并排显示原图、保留原始分辨率的黑白处理预览，下方显示最终二维码。

### 图片细节

图片按**最终二维码版本**直接从原图采样，不先压成固定大小的像素图。图片使用完整的中心宽高区域，不套用文字的高度限制。

- **Logo**：适合标志、文字图片、图标和线稿，以区域最小值采样保留细线和硬边。
- **照片**：适合连续明暗和色彩照片，使用灰度、对比度调整及有序抖动表达黑白层次。
- **自动**：纯黑白素材优先保留线条，其余素材比较两种处理效果，选择局部明暗更接近原图的结果。

高级设置包括手动黑白阈值、对比度、白边阈值、反色、是否裁边及重置。白边阈值默认为 245；浅色内容被误判为空白时可提高该值或关闭裁边。

需要更细的图片时，提高二维码版本；增大每模块像素只增加导出尺寸，不增加图案可用的模块数。细于一个模块的结构仍无法完整还原，对齐图案所在位置也必须保留。

## 命令行

```bat
python app.py -t "https://example.com" -a "Margin" -o out.png --svg out.svg
python app.py -t "https://example.com" --image logo.png --image-mode logo --strategy fidelity --version 25 -o logo-qr.png --svg logo-qr.svg
python app.py -t "https://example.com" --image photo.jpg --image-mode photo --contrast 1.2 --ratio 0.62 -o photo-qr.png
python app.py -t "hello" -a "字形" --font "C:\Windows\Fonts\msyh.ttc" --font-index 1 -o text-qr.png
```

打包后的 `MarginCLI.exe` 接受相同参数；`Margin.exe` 为无控制台的窗口程序。

| 参数 | 说明 | 默认 |
|---|---|---|
| `-t/--text` | 扫码内容 | 必填 |
| `-a/--art` | 中心文字，与 `--image` 互斥 | 空 |
| `--image` | 中心图片文件路径 | 无 |
| `--image-mode` | `auto` / `logo` / `photo` | `auto` |
| `--strategy` | `scan` 扫码优先 / `fidelity` 还原优先 | `scan` |
| `--version` | 版本 1–40 | 文字按长度使用 v10/12/15 起；图片 v12 起 |
| `--ec` | 纠错等级 H/Q/M/L，图案推荐 H | H |
| `--mask` | 掩码 0–7 | 自动比较 |
| `--budget` | 每块预算上限，实际值受策略和容量约束 | 10 |
| `--dot` | 点径 0.4–1.0；1.0 为实心方块 | 0.66 |
| `--scale` | 每模块像素，正整数 | 20 |
| `--quiet` | 静区模块数，至少 4 | 4 |
| `--font` | TTF/OTF/TTC/OTC 文件路径 | 微软雅黑粗体 |
| `--font-index` | 字体集合中的索引，从 0 开始 | 0 |
| `--ratio` | 图案最大宽度占比，0.1–0.8 | 0.62 |
| `--threshold` | 手动黑白阈值 0–255 | 自动 |
| `--contrast` | 图片对比度，0.2–4 | 1.0 |
| `--invert` | 反转图片黑白 | 关闭 |
| `--no-crop` | 不裁外围白边 | 默认裁边 |
| `--white-threshold` | 白边阈值，1–255 | 245 |

图片自动版本最多比较三个：从能容纳内容且不低于 v12 的版本开始，间隔 3，最高 v40。手动版本和掩码始终遵守指定值。自检失败时 CLI 返回 2，不输出文件；没有安装 ZXing 时明确显示「未验证」，允许导出。

例如 v12 H 的每块容量为 14，默认 `--budget 10 --strategy scan` 的有效预算为 9。可以在生成结果中查看实际版本、掩码、各块用量、有效预算、图案一致度及扫码结果。

## 开发与打包

```bat
python -m pip install -r requirements.txt
python app.py --selftest
python -m unittest discover -s tests -v
build.bat
```

`build.bat` 在 `build/.venv` 中从同一依赖清单安装依赖，避免打包电脑上其他项目的包；生成带图标和应用资源的单文件 `dist/Margin.exe` 与 `dist/MarginCLI.exe`。仓库不追踪构建产物。

主要模块：

- `app.py`：GUI / CLI 入口、文字扫码自测。
- `margin/core.py`：二维码结构、预算、候选选择、扫码验证、渲染及最终矩阵。
- `margin/fonts.py`：Windows 字体枚举、原生渲染、字体文件和集合、缺字检查。
- `margin/art.py`：图片读取、裁边、灰度与黑白转换、细节采样。
- `margin/gui.py`：后台生成、字体搜索、图片预览和联动数值控件。
- `margin/svg.py`：最终矩阵的矢量导出。
- `tests/`：图片、字体、纠错预算、扫码、导出和 Tk 组件测试。

主要面向 Windows；其他系统可通过 CLI 显式指定字体文件或使用图片生成。系统字体不随 EXE 分发，输入图片和字体均在本机处理。
